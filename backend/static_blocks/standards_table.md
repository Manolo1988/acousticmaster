## 国家标准指标对照表

根据《厅堂扩声系统设计规范》GB 50371-2006，会议类扩声系统二级指标要求如下：

| 指标项目 | 二级指标要求 | 本方案设计值 |
| --- | --- | --- |
| 稳态最大声压级 | ≥90 dB | ≥92 dB |
| 传声增益（125Hz~4kHz 平均） | ≥-8 dB | ≥-6 dB |
| 声场不均匀度（1kHz） | ≤8 dB | ≤6 dB |
| 系统总噪声级 | ≤-30 dB(A) | ≤-35 dB(A) |
| 语言传输指数（STIPA） | ≥0.6 | ≥0.65 |

根据《会议系统电及音频的性能要求》GB/T 15381-94，会议发言系统主要指标如下：

| 指标项目 | 标准要求 |
| --- | --- |
| 频率响应误差（100Hz~16kHz） | ≤±1 dB |
| 通道串扰衰减 | ≥60 dB |
| 信号传输衰减 | ≤0.5 dB/10m |
| 信号延迟 | ≤1 ms |
