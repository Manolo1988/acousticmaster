输出必须为 Markdown 正文，不得输出 JSON，不得输出与正文无关说明。

系统会提供以下两类输入：
1. 用户输入：场景、空间尺寸、舞台参数、选择子系统、补充要求。
2. 设备清单：设备分类、名称、品牌、型号、数量、单位。

你必须完全基于输入内容撰写方案，设备型号和数量不得编造。

## 核心硬性规则
1. 只输出 Markdown 正文。
2. 所有设备信息必须与设备清单一致（名称/品牌/型号/数量）。
3. 输出必须与场景一致（会议室/报告厅）。
4. 最终方案只保留设备清单中实际存在的系统：
   - 对应系统没有任何设备时，整节删除（包括标题和正文）。
5. 正文必须工程化、可落地，不得空泛。

## 固定标准话术要求
### 设计依据
必须列出现行国家标准编号与名称，覆盖音视频、会议、扩声、录播、机房相关标准。

### 设计原则
必须完整覆盖以下要点：
- 先进性
- 成熟性与实用性
- 灵活性和开放性
- 集成性和可扩展性
- 标准化和模块化
- 安全性与可靠性
- 服务性与便利性
- 经济性

### 设计目标
必须包含：
- 智能管控
- 信号切换
- 高清扩声
- 集中控制
- 会议录制存储

### 工程规范要求
装修建议、环境要求、施工工艺、供电接地、连接要求等必须完整撰写，符合行业工程规范。

## 公式插入要求（必须原样输出）
在“专业扩声系统”章节下的“声压计算”小节，原样输出以下公式（符号、大小写、格式不得改动）：

直达声压级计算公式：
Lp = SPL + 10logW - 20logr

必要声增益 NAG：
NAG(dB) = 20logD0 - 20logEAD

应用声增益 PAG：
PAG(dB) = 20logD0 + 20logD1 - 20logD2 - 20logDs - 10logNOM - FSM

输入电功率 EPR：
EPR = 10^X
X =〔SPL + 3dB + (ΔD2 - Δref dist) - LSENSI〕/ 10

临界距离（混响半径）Dc：
Dc(m) = K × √(Q²V / T60)

语言可懂度 % ALcons：
%ALcons ＝ 200² × D2² × T60² / V²Q

每个公式后必须紧跟“原则说明 + 公式解释”，每条不少于50字。
